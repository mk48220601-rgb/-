# 우진이 톡! 🦁

**우진이만을 위한 우리 가족 채팅 앱** — 휴대폰(모바일 브라우저)에서 바로 접속하는 실시간 채팅방입니다.

아이 이름(우진), 좋아하는 캐릭터풍(라이언풍 노란 사자 **리오**), 관심사(나라·국기, 수학, 끝말잇기, 농담·말장난)에 맞춰 꾸몄어요.

> ⚠️ **라이언은 저작권 있는 캐릭터**라 공식 이미지를 직접 그려 넣지 않았어요. 노란 사자 느낌의 오리지널 캐릭터 **리오**로 대신했고, 원하시면 아래 "마스코트 교체"를 따라 공식 이미지로 바꿀 수 있어요.

---

## ✨ 기능

| 기능 | 설명 |
|---|---|
| 💬 실시간 채팅 | WebSocket 기반, 모든 가족이 동시에 이야기 가능 |
| 🦁 라이언(리오) 놀이 | 끝말잇기 시작 / 말장난 / 나라·국기 상식 / 수학 문제를 눌러서 라이언이 한마디 |
| 🛡️ 안전 말쓰기 지킴이 | 욕설 등은 자동으로 🍬로 바뀌고, 원문은 부모님에게만 기록됨 |
| 👪 부모 모드 | PIN 입력 후: 멤버 관리(조용히/나가기), 지킴이 단어 추가·삭제, 기록 확인, 대화 내보내기 |
| 😊 스탬프 | 메시지에 하트·박수·웃음 등 스탬프 찍기 |
| 🔊 소리 내어 읽기 | 새 메시지를 아이 목소리 톤으로 읽어주기 (TTS) |
| ✏️ 쉬운 입력 | 문구 / 이모지 / 놀이 퀵바로 글쓰기 어려운 아이도 한 번 터치로 대화 |
| 🎈 귀여운 디자인 | 사탕색 팔레트, 동그란 필로우 말풍선, 떠 있는 풍선 |

## 🚀 실행 방법

```bash
npm install
npm start          # 기본 http://localhost:3000
```

환경변수로 바꿀 수 있어요:

```bash
PORT=8080 PARENT_PIN=1234 npm start
```

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `PARENT_PIN` | `0000` | 부모 모드 비밀번호 — **꼭 바꾸세요** |

## 🛡️ 부모 모드 사용법

1. 채팅방 오른쪽 위 **🛡️ 부모님** 버튼 탭
2. PIN 입력 (`0000` 또는 환경변수 값)
3. 할 수 있는 일:
   - **우리 가족**: 멤버를 "조용히"(뮤트) 또는 "나가 해"(퇴장)
   - **지킴이 단어**: 욕설 등 막고 싶은 단어 추가/삭제
   - **지킴이 기록**: 🍬로 바뀐 메시지의 원문 확인
   - **대화 기록 내보내기**: txt 파일로 저장

## ☁️ 배포하기 (인터넷에 올려 전화기에서 항상 사용)

**Render (무료) — 가장 쉬움**
1. GitHub에 이 폴더를 업로드
2. [render.com](https://render.com) → **New → Web Service** → 저장소 연결
3. Build: `npm install` / Start: `npm start`
4. 배포된 URL을 가족 휴대폰에 저장 → 끝!

**Railway / Fly.io / 집 서버(VPS)**도 마찬가지로 `npm start`만 실행하면 돼요.
(WebSocket을 쓰므로 리버스 프록시 사용 시 `/ws` 경로의 Upgrade를 허용해 주세요.)

## 🎨 맞춤 방법 (개발자용)

- **문구/이모지/놀이**: `public/app.js` 맨 위의 `PHRASES`, `EMOJIS`, `PLAY` 배열 수정
- **라이언 말 자료**: `server.js`의 `LION` 객체 (말장난/나라/수학/끝말잇기)
- **테마 색**: `public/style.css` 맨 위 `:root` 변수
- **마스코트(리오) 교체**: `public/index.html`의 `<svg class="mascot">`를 라이선스 확보한 라이언 이미지(`<img>`)로 교체

## ⚠️ 참고 (한계)

- 메시지·멤버는 **서버 메모리에만** 저장됩니다. 서버를 재시작하면 초기화돼요. (영구 저장이 필요하면 SQLite/DB 연결을 추가하세요)
- 로그인은 없습니다. **URL을 아는 사람은 누구나 들어올 수 있어요.** 가족 전용으로 쓰려면 URL을 가족끼리만 공유하고, 더 안전하게 하려면 비밀번호 로그인을 추가하세요.
- 현재는 한 개의 방(우리 가족방)입니다.
